# Dota 2 JSON API 


A free, developer-friendly collection of **Dota 2 game data in JSON format**, designed to be used like a lightweight API for applications, websites, bots, tools, dashboards, and other Dota 2-related projects.

The goal of this repository is to provide structured, simple, reusable, and easily accessible JSON data for developers who need Dota 2 information in their projects.


##  Features

-  Dota 2 data in clean JSON format
-  Simple and lightweight structure
-  Easy to consume from websites and applications
-  Suitable for mobile and desktop applications
-  Useful for bots, tools, and automation
-  Suitable for dashboards and statistics projects
-  New patch notes are being added quickly
-  Developer-friendly and easy to integrate
-  Community-driven data updates
-  Open for contributions
